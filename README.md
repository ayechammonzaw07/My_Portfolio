# My Portfolio

This project is a personal portfolio website built to showcase my background, skills, experience, projects, and contact information.

## What it includes

- Home page
- About section
- Skills and services
- Experience timeline
- Project showcase
- Contact form

## Tech used

- PHP
- Laravel
- Blade templates
- Custom CSS
- Vite

## How to run

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan serve
```

## Contact

If you want to reach out, use the contact section on the website or connect through the details provided in the portfolio.
